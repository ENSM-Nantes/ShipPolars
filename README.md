# PolarInject
Send Polar read from Shiplify.io to BridgeCommand 

## Requirements
libgtk-4-dev

## Build
```gcc $(pkg-config --cflags gtk4) -o PolarInject *.c $(pkg-config --libs gtk4)```

## Use
./PolarInject
